# A Little To The Left - Web Demo

## Introduction
This site was developed to demonstrate a level of the video game A Little To The Left, ported to the web. It is adapted from the [LinkedIn Learning Course "HTML, CSS, and JavaScript: Building The Web"](https://github.com/LinkedInLearning/html-css-and-javascript-building-the-web-4479542) Terrarium Project, changing the view of the project and adding code to allow pencils to snap to appropriate slots and reset their positioning upon clicking the reset button.

## Functionality
In order to use this site, open the link (https://aaryhash.github.io/a-little-to-the-left-web-demo/). The simple game can be played by dragging pencils into their slots, the highlighted rectangles, where they will snap into place. The reset button on the left side of the screen, or reloading the site, can also be used to snap all pencils back to their original state.

## Future Plans
If this project were to continue, some additional features could be to add actual solutions for placing each pencil in the correct order, as well as a level select with a few more levels. Music and animations could also be added to more closely align with the original game.
